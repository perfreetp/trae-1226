# 小红书品牌合作后端服务 API 文档

## 项目概述

面向品牌方后台、达人小程序和财务系统提供统一能力的后端服务，采用 Node.js + TypeScript + Express + Prisma + SQLite 技术栈。

---

## 快速开始

### 1. 安装依赖
```bash
npm install
```

### 2. 初始化数据库
```bash
npx prisma migrate dev --name init
```

### 3. 生成 Prisma 客户端
```bash
npx prisma generate
```

### 4. 导入种子数据
```bash
npx prisma db seed
# 或
npm run prisma:seed
```

### 5. 启动开发服务
```bash
npm run dev
```

服务地址: `http://localhost:3000`
API 前缀: `/api/v1`

## 认证说明

除 `/health` 和 `/auth/login` 外，所有接口需在请求头中携带：
```
Authorization: Bearer <token>
```

### 8. 通知模块 `/api/v1/notifications`

**模板管理**

| 方法 | 路径           | 说明       | 权限     |
|------|----------------|------------|----------|
| GET  | `/templates`   | 模板列表   | 管理员   |
| POST | `/templates`   | 新增模板   | 管理员   |

**发送通知**

| 方法 | 路径          | 说明                       | 权限         |
|------|---------------|----------------------------|--------------|
| POST | `/send`       | 自定义批量发送             | 管理员/运营  |
| POST | `/send/scene` | 场景化发送（8种业务场景）  | 管理员/运营  |

**场景化通知支持：**
- `INVITATION_PUBLISHED` 邀约发布（通知达人）
- `INVITATION_ACCEPTED` 达人接受（通知运营）
- `INVITATION_REJECTED` 达人拒绝（通知运营）
- `CONTENT_SUBMITTED` 内容待审（通知运营）
- `CONTENT_REVIEWED` 审核结果（通知达人）
- `SETTLEMENT_APPROVED` 结算通过（通知达人+财务）
- `SETTLEMENT_PAID` 付款完成（通知达人）
- `RISK_ALERT` 风控告警（通知运营）

**个人通知中心**

| 方法 | 路径              | 说明              | 权限 |
|------|-------------------|-------------------|------|
| GET  | `/mine`           | 我的通知（分页）   | 登录 |
| GET  | `/mine/unread-count` | 未读数量统计   | 登录 |
| POST | `/:id/read`       | 标记单条已读       | 登录 |
| POST | `/read-all`       | 全部标记已读       | 登录 |

**管理员**

| 方法 | 路径    | 说明                 | 权限     |
|------|---------|----------------------|----------|
| GET  | `/all`  | 全量通知查询（筛选） | 管理员   |

## 统一响应格式

```json
{
  "code": 0,
  "message": "success",
  "data": { ... },
  "total": 100,
  "page": 1,
  "pageSize": 20
}
```

- `code = 0` 表示成功
- 非 0 表示失败，`message` 为错误描述

## 错误码参考

| 错误码 | 说明               |
|--------|--------------------|
| 401    | 未认证/Token 无效  |
| 403    | 权限不足           |
| 404    | 资源不存在         |
| 422    | 参数校验失败       |
| 1001   | 用户名或密码错误   |
| 2001   | 登录账号已存在     |
| 2002   | 小红书ID已注册     |
| 2010   | 标签已存在         |
| 2020   | 达人已在黑名单     |
| 3010~  | 邀约相关错误       |
| 4010~  | 内容相关错误       |
| 5010~  | 数据相关错误       |
| 6010~  | 结算相关错误       |
| 7001~  | 风控相关错误       |
| 8001~  | 通知相关错误       |
